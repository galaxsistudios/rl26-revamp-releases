# RL26 Revamp

A mod for **Rugby League 26** on PC: gameplay and AI changes, career mode additions, kits, logos, stadium and
broadcast presentation, and more.

This repository only holds the release downloads. Each release has:

| File | For |
|---|---|
| `RL26-Revamp-<version>.zip` | a new install (the full package) |
| `RL26-Revamp-update-<previous>-to-<version>.zip` | players on the release before it (only the files that changed) |
| `release.json` | the release's manifest, read by the launcher (version, notes, files and their hashes) |

## Installing

Use the **RL26 Revamp launcher** (coming soon). It installs the mod, keeps it updated, adds the optional Rugby 25
Expansion if you own Rugby 25, and puts the game back to stock with one click.

You need:

- Rugby League 26 on Steam (PC), updated to the build the release names
- Windows 10 or 11
- About 6 GB free on the game's drive

The mod is built on your PC from your own copy of the game: no game files are distributed here. The launcher
backs up your saves before it installs or uninstalls anything.

## Notes

- Close the game before installing, updating or uninstalling.
- If Windows "Controlled folder access" is on, allow the launcher through it.
- Blobset Tools mods can be used alongside the Revamp in **Mod Loader mode only**.
